# Pragati Academy

A fictional, premium Indian education-platform concept for **Pragati Academy** — a NEET / JEE / UPSC / foundation / career-prep institute in Lucknow, Uttar Pradesh. Built as a portfolio piece for **Autopend**, demonstrating the full digital infrastructure behind an education business: not just a coaching website, but the marketing site, admissions CRM, WhatsApp automation console and student portal that run behind it.

All four pages are self-contained, single-file HTML/CSS/JS — no build step, no external requests, fonts embedded inline (Sora + Libre Franklin). Open any file directly in a browser, or view the hosted versions below.

## Pages

| Page | File | Description |
|---|---|---|
| Marketing site | `index.html` | Programs, admissions flow, results, faculty, testimonials, journal |
| Admissions CRM | `crm.html` | Leads, counselling, applications, enrolments, follow-ups, counsellor performance |
| WhatsApp automation | `whatsapp.html` | Live branching enquiry chat, automated follow-up sequence, message templates |
| Student portal | `portal.html` | Attendance, mock-test performance, fees, mentorship |

## Data

All content — students, faculty, leads, fees, results — is fictional demo data, clearly labelled as such throughout. No real people, institutions, or records are represented.
